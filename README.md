Midnight Gallery — a top-down stealth game. You are Wren, a thief slipping into the Meridian Gallery at night: steal three ledgers and reach the skylight exit unseen. Guards patrol with vision cones, crates and planters hide you, dark carpet slows detection, and a detection meter gives you a chance to recover. Noise matters — sprint loud, sneak silent, or throw a coin to pull a guard away. Keyboard + mouse, static files only, plays offline in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
